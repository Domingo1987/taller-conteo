Taller de conteo

    Mesa de trabajo

    Agregá herramientas, completá los números y combiná resultados. Cada herramienta queda con un nombre (R1, R2…) para usarla después.

    Cargar ejercicios desde JSON

    Pegá el JSON o elegí un archivo. El ejemplo de abajo tiene la estructura esperada: podés copiarlo, editarlo y volver a cargarlo.

    Estructura del JSON

    titulo (texto) y ejercicios (lista). Cada ejercicio lleva numero, parte, titulo, enunciado e items. Cada ítem lleva id (a, b, c…), pregunta y respuesta (entero). Opcionales por ítem: pistas (lista de textos), errores_comunes (lista de {"valor": número, "mensaje": texto}), herramientas_sugeridas y explicacion (se muestra solo al acertar). Herramientas válidas: casillas, factorial, letras, arreglo, potencia, combinacion, bloque, combinar.
